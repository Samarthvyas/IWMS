Intelligent Waste Management System (IWMS)

IWMS is a full-stack web application built with Python, Django, and Django REST Framework to streamline waste reporting and management. Users can submit waste reports with images, while the system uses AI-based classification to identify waste types and automatically assign priorities.

Key Features
♻️ Waste Reporting – Users can submit waste reports with image uploads.
🤖 AI Waste Classification – Automatically identifies the type of waste from uploaded images.
🚦 Automatic Priority Assignment – Assigns priority based on the classified waste type.
🔐 JWT Authentication – Secure user registration and login using JWT.
👤 Citizen Dashboard – View submitted reports and track their status.
🛠️ Admin Dashboard – Manage reports, users, and report statuses.
📊 Report Management – View report details and update their status.
🔒 Role-Based Access Control – Restricts administrative operations to authorized users.
Tech Stack

Backend: Python, Django, Django REST Framework
Frontend: Django Templates, Bootstrap
Database: SQLite
Authentication: JWT
AI: Image-based waste classification
Version Control: Git, GitHub
